# Custom Metrics — ตัวเลขที่คุณอยากเก็บเอง

เพิ่มระบบ "ฟิลด์ตัวเลขกำหนดเอง" ให้บันทึกค่าอย่าง Fibo level, จำนวนจุดที่ราคาวิ่ง, RR ที่ตั้งไว้ ฯลฯ ในหน้าเก็บเทรด แล้วนำไปคำนวณค่าเฉลี่ย/สถิติอัตโนมัติ

## 1. ตั้งค่าฟิลด์เอง (Settings → Metrics)
- สร้าง/แก้ไข/ลบฟิลด์ได้เอง ต่อโปรไฟล์เดียวกับ Conditions/Tags
- แต่ละฟิลด์กำหนด: ชื่อ (เช่น "Fibo", "Points"), หน่วย (pts, %, R, ว่าง), ทศนิยม, ค่าต่ำสุด/สูงสุด (ไม่บังคับ), เปิด/ปิดใช้งาน
- จัดลำดับการแสดงผลได้

## 2. กรอกค่าในหน้าเทรด
- ในฟอร์มเทรด (ทั้งเพิ่มใหม่และแก้ไข) มีส่วน "Metrics" แสดงเฉพาะฟิลด์ที่เปิดใช้งาน
- ไม่บังคับกรอก เว้นว่างได้ ปุ่มกรอกเร็วบนมือถือ (numeric keyboard)
- หน้ารายละเอียดเทรดแสดงค่าที่กรอกไว้เป็นตาราง

## 3. วิเคราะห์ตัวเลข
เพิ่มการ์ด "Custom Metrics" ในหน้า Dashboard (ตามช่วงวันที่ที่กรองอยู่):
- ต่อฟิลด์: ค่าเฉลี่ย, มัธยฐาน, ต่ำสุด/สูงสุด, จำนวนไม้ที่มีข้อมูล
- แยกค่าเฉลี่ยตามผล Win / Loss (เช่น "ไม้ที่ชนะ ราคาวิ่งเฉลี่ย 42 จุด, ไม้แพ้ 11 จุด")
- ความสัมพันธ์กับผลงาน: แบ่งค่าเป็น 3 ช่วง (ต่ำ/กลาง/สูง) แล้วโชว์ Avg R + Win rate ของแต่ละช่วง เพื่อบอกว่าค่าช่วงไหนทำกำไรดีสุด
- Insight อัตโนมัติเพิ่ม เช่น "Fibo 0.618 ให้ค่า R เฉลี่ยสูงสุด"

## 4. Export / Import
- CSV export เพิ่มคอลัมน์ของทุกฟิลด์
- CSV import แมปคอลัมน์เข้าฟิลด์ที่มีอยู่ได้

## รายละเอียดเชิงเทคนิค
- ตารางใหม่ `trade_metrics` (นิยามฟิลด์: user_id, profile_id, name, unit, decimals, min/max, sort_order, is_active) และ `trade_metric_values` (trade_id, metric_id, value numeric) พร้อม RLS + GRANT ตามรูปแบบเดิม
- ไฟล์ใหม่: `src/pages/SettingsMetrics.tsx`, `src/components/dashboard/MetricsAnalysisCard.tsx`
- แก้: `TradeForm.tsx` (บันทึกค่าแบบ upsert), `TradeDetail.tsx`, `Dashboard.tsx`, `Settings.tsx` (แท็บใหม่), `src/lib/csv.ts`, `ImportTradesDialog.tsx`
- คำนวณสถิติฝั่ง client จากข้อมูลที่ดึงมาแล้ว ไม่เพิ่ม query หนัก

## ลำดับงาน

3. การ์ดวิเคราะห์ใน Dashboard + Insight
4. CSV export/import
